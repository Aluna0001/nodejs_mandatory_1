Express.js

Express er et web application framework til Node.js:

Basic Server Setup

import express from 'express';
const app = express();

app.get('/', (req, res) => {
  res.send('Hello World!');
});

app.listen(8080, () => {
  console.log('Server running on port 8080');
});

Vigtige koncepter

  • Routing: Definere endpoints (GET, POST, PUT, DELETE)
  • Middleware: Funktioner der kører mellem request og response
  • Static files: Servere CSS, images, JavaScript
  • Server-Side Rendering: Generere HTML på serveren

REST API

Express bruges ofte til at lave RESTful APIs med JSON responses.
