Terminal Commands

Vigtige terminal kommandoer jeg har lært:

Navigation

  • pwd - Print working directory
  • ls - List filer og mapper
  • cd [mappe] - Change directory
  • mkdir [navn] - Opret ny mappe

Node.js kommandoer

  • node [fil] - Kør JavaScript fil
  • npm init - Initialiser nyt projekt
  • npm install [package] - Installer package
  • npm start - Start applikation

Git kommandoer

  • git add . - Stage alle ændringer
  • git commit -m "besked" - Commit ændringer
  • git push - Push til remote
