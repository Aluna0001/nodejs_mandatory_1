Node.js

Hvad jeg har lært om Node.js:

Hvad er Node.js?

Node.js er et JavaScript runtime environment der lader os køre JavaScript uden for browseren.

Vigtige koncepter

  • Modules: Import/export af funktioner mellem filer
  • npm: Node Package Manager til at installere packages
  • package.json: Fil der beskriver projektet og dependencies
  • Async/Await: Håndtering af asynkrone operationer

CommonJS vs ES Modules

CommonJS: require() og module.exports

ES Modules: import og export (moderne standard)
